# اپلیکیشن مدیریت مالی

این پروژه یک اپ وب ساده (بدون نیاز به React یا ابزار Build) است که با Capacitor به یک پروژه اندرویدی تبدیل می‌شود و از طریق GitHub Actions به‌صورت خودکار APK می‌سازد.

## ساختار پروژه
- `www/` — کل اپلیکیشن (HTML + CSS + JS خام، بدون نیاز به npm build)
- `capacitor.config.json` — تنظیمات اپ (نام، شناسه بسته)
- `.github/workflows/build-apk.yml` — ورک‌فلوی خودکار ساخت APK

## مراحل استفاده

1. این پوشه را در یک ریپازیتوری جدید در GitHub آپلود/پوش کنید.
2. به تب **Actions** در ریپازیتوری بروید و مطمئن شوید Actions فعال است.
3. ورک‌فلوی «Build Android APK» به‌صورت خودکار بعد از هر Push روی شاخه `main` اجرا می‌شود (یا از دکمه Run workflow به‌صورت دستی اجرا کنید).
4. بعد از پایان اجرا (چند دقیقه طول می‌کشد)، وارد همان اجرا (run) شوید و از بخش **Artifacts** فایل `finance-app-debug-apk` را دانلود کنید. داخل آن فایل `app-debug.apk` است.
5. فایل APK را روی گوشی اندروید منتقل و نصب کنید (نیاز به فعال‌کردن «نصب از منابع ناشناس» دارید).

## نکات مهم درباره‌ی حفظ اطلاعات بین نصب‌ها

- اطلاعات مالی در حافظه محلی گوشی (`localStorage` داخل WebView) ذخیره می‌شود، نه در خود فایل APK. یعنی **نصب یک نسخه‌ی جدید روی نسخه‌ی قبلی (Update) اطلاعات را پاک نمی‌کند**، اما **Uninstall کردن اپ قطعاً همه‌ی اطلاعات را پاک می‌کند** (رفتار استاندارد اندروید برای هر اپی).
- برای این‌که نصب نسخه‌ی جدید واقعاً «به‌روزرسانی» حساب شود (نه نصب یک اپ کاملاً جدید)، امضای دیجیتال (signing key) APK باید در همه‌ی build ها یکسان بماند. در این پروژه یک فایل `android-debug.keystore` ثابت اضافه شده و ورک‌فلوی GitHub Actions در هر اجرا از همین فایل استفاده می‌کند؛ بنابراین همه‌ی APK هایی که از این ریپازیتوری ساخته می‌شوند امضای یکسان دارند و نصب نسخه‌ی جدید روی نسخه‌ی قبلی باید بدون پاک‌شدن اطلاعات انجام شود (گوشی پیام «برنامه به‌روزرسانی شد» می‌دهد، نه نصب جدید).
- با این‌حال، برای اطمینان کامل (مثلاً اگر گوشی را عوض کردید یا مجبور به Uninstall شدید)، از دکمه **⚙️ تنظیمات** (بالای صفحه) به بخش **«پشتیبان‌گیری و بازیابی اطلاعات»** بروید:
  - **دریافت فایل پشتیبان** — یک فایل JSON از همه‌ی اطلاعات (درآمد، هزینه، بدهی، طلب، یادداشت، دفترهای موقت، دسته‌بندی‌ها) می‌سازد و منوی اشتراک‌گذاری اندروید باز می‌شود تا آن را ذخیره کنید یا بفرستید (گوگل‌درایو، تلگرام‌به‌خود و...).
  - **بازیابی از فایل پشتیبان** — همان فایل JSON را انتخاب می‌کنید تا اطلاعات در برنامه بازگردانی شود (این کار اطلاعات فعلی را جایگزین می‌کند، پس قبلش تأییدیه می‌پرسد).
  - توصیه می‌شود **قبل از هر Uninstall یا تعویض گوشی**، حتماً از همین گزینه یک پشتیبان بگیرید.
- این APK به‌صورت **debug** ساخته می‌شود (برای انتشار رسمی در Google Play باید نسخه‌ی release و امضای جداگانه بسازید؛ راهنمای رسمی Capacitor/Android را ببینید).
- برای تغییر نام اپ یا شناسه بسته، فایل `capacitor.config.json` را ویرایش کنید (`appName`, `appId`). **توجه: اگر appId را تغییر دهید، اندروید آن را یک اپ کاملاً جدید می‌داند و اطلاعات نسخه‌ی قبلی به آن منتقل نمی‌شود** (باز هم از پشتیبان‌گیری/بازیابی برای انتقال استفاده کنید).
- آیکن اپ (لوگو) در پوشه `resources/icons` است و ورک‌فلو آن را خودکار بعد از `cap add android` در پروژه اندروید کپی می‌کند. برای تغییر لوگو، همین فایل‌های `ic_launcher*.png` را جایگزین کنید. لوگوی داخل برنامه `www/logo.png` است.

## اجرای محلی (اختیاری، برای تست قبل از ارسال به GitHub)

اگر Node.js و Android Studio روی سیستم خودتان نصب است:

```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```

سپس از داخل Android Studio روی Run بزنید.


## ساختار برنامه
- **نوار بالا:** نمای کلی، درآمدها، هزینه‌ها، بدهی، طلب (و دکمه‌های جستجو 🔍 و تنظیمات ⚙️)
- **نوار پایین:** هزینه‌های آتی، یادداشت، بایگانی، گزارش، دفتر موقت
- **بایگانی:** ماه‌های گذشته (درآمد/هزینه)، سابقه طلب، سابقه بدهی
- **گزارش:** با انتخاب بازه تاریخی، جمع کل و ریز درآمدها و هزینه‌ها
- **دفتر موقت:** دفترهای جدا (مثلاً سفر) با جمع هزینه‌ها؛ در موجودی، بایگانی و گزارش حساب نمی‌شود
